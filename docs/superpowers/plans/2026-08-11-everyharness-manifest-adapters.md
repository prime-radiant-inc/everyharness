## Global Constraints

- Node `>=20`, ESM, TS strict, `.js` relative imports. Runtime deps stay exactly: `commander`, `yaml`, `zod`, `ajv`.
- Exit codes unchanged: 0 ok / 1 config / 2 schema / 3 drift.
- No silent drops: any component a harness can't express produces a warning naming component + harness, and the adapter's support matrix entry says so.
- Generated non-JSON files begin with marker `# GENERATED by everyharness — edit everyharness.yaml instead` (bash comments) placed on line 2 of shell scripts (line 1 is the shebang); JSON stays marker-free; markdown gets an HTML comment `<!-- GENERATED by everyharness — edit everyharness.yaml instead -->` as its first line.
- Adapters NEVER emit a path that equals a configured source component path (`components.*` files/dirs) — the generator throws ConfigError if one tries.
- All new adapters follow the claude-code adapter's structure: one module in `src/adapters/`, registered in `src/adapters/index.ts`, `support` honestly reflecting what the adapter EMITS (not what the harness could theoretically do).
- TDD per task; pristine output (the console.error/warn spy guard from Plan 1 must stay green).

## Design decisions locked by this plan (carried from Plan 1 final review)

1. **Collision dedupe:** two adapters emitting the same path is an error UNLESS content and executable flag are byte-identical — then the file is emitted once (first adapter owns it in the manifest) and no warning is raised.
2. **Stale-file pruning:** `generate()` loads the prior manifest (if any) before saving the new one. Entries absent from the new FileSet: if the on-disk file still hash-matches its recorded entry → delete it (and remove now-empty parent dirs up to but excluding root); if it exists but hash differs → leave it and warn (`stale generated file <path> was hand-modified; delete it or move changes into everyharness.yaml`); if already gone → ignore. `GenerateResult` gains `pruned: string[]`.
3. **win32 exec-bit:** `checkDrift` skips the executable-bit comparison when `process.platform === 'win32'` (content hash still checked). Implemented with an options seam: `checkDrift(root, opts?: { checkExecBit?: boolean })` defaulting to `process.platform !== 'win32'`.
4. **Source MCP default becomes `.mcp.json`** (Claude Code's real default). This frees root `mcp.json` for the Agent Plugins 1.0 adapter's *generated* file and removes Plan 1's `'.mcp.json'`-vs-`'mcp.json'` constant mismatch. Kitchen-sink fixture renames accordingly.
5. **Bootstrap wrapper tag** for generated session-start context is plugin-neutral: `<plugin-bootstrap plugin="NAME">…</plugin-bootstrap>` with an intro line naming the skill. (Superpowers' `<EXTREMELY_IMPORTANT>` language is its own tuned content, not a template for third-party plugins.)
6. **Hooks merging (claude-code):** user hooks stay source at `components.hooks`; when bootstrap is enabled the adapter emits `hooks/everyharness/{session-start,run-hook.cmd,hooks.json}` where the generated `hooks.json` = user's hooks with the bootstrap SessionStart entry appended, and plugin.json's `hooks` key points at the generated file. Regeneration recombines; the user file is never touched.
7. **Cursor hooks are bootstrap-only in v1**: generated `hooks/everyharness/hooks-cursor.json` carries only the sessionStart bootstrap entry; if the user has their own hooks, warn (`cursor: user hooks are not translated in v1`) and mark cursor `hooks: 'partial'` — 'none' if no bootstrap either.
8. **Codex `hooks` guard:** `.codex-plugin/plugin.json` always sets `"hooks": {}` — Codex's loader falls back to auto-registering `hooks/hooks.json` unless the manifest holds a literal empty object (superpowers' `tests/codex/test-marketplace-manifest.sh` documents this trap). Warn when the plugin has hooks (`codex: hooks are not supported; bootstrap relies on native skill discovery`).

```ts
  if (path === 'everyharness.yaml') return true
  if (path === config.components.hooks || path === config.components.mcp) return true
  for (const dir of [config.components.skills, config.components.commands, config.components.agents]) {

const byPath = new Map<string, { owner: string; file: GeneratedFile }>()
for (const adapter of active) {
  const result = adapter.emit(model)
  for (const file of result.files) {
    if (isSourcePath(file.path, model.config)) {
      throw new ConfigError(`adapter "${adapter.name}" would overwrite source file ${file.path}`)
    }
    const existing = byPath.get(file.path)
    if (existing) {
      const identical =
        existing.file.content === file.content &&
        Boolean(existing.file.executable) === Boolean(file.executable)
      if (!identical) {

      continue // identical content: dedupe silently
```

`src/manifest.ts` — extract and export the loader used by `checkDrift`:

```ts
export function loadManifest(root: string): GenerationManifest | undefined {
  const abs = join(root, MANIFEST_PATH)
  if (!existsSync(abs)) return undefined
  let manifest: unknown
  try {
    manifest = JSON.parse(readFileSync(abs, 'utf8'))
  } catch (e) {
    throw new ConfigError(`${MANIFEST_PATH} is not valid JSON: ${(e as Error).message}`)
  }
  const m = manifest as GenerationManifest
  if (typeof m !== 'object' || m === null || typeof m.files !== 'object' || m.files === null) {
    throw new ConfigError(`${MANIFEST_PATH} has an unrecognized format — regenerate with \`everyharness generate\``)
  }
  return m
}
```

```ts
const prior = loadManifest(root)
const pruned: string[] = []
if (prior) {
  const newPaths = new Set(files.map((f) => f.path))
  for (const [path, entry] of Object.entries(prior.files)) {
    if (newPaths.has(path)) continue
    const abs = join(root, path)
    if (!existsSync(abs)) continue
    if (sha256(readFileSync(abs, 'utf8')) === entry.sha256) {
      rmSync(abs)
      pruned.push(path)
      let parent = dirname(abs)
      const rootAbs = resolve(root)
      while (resolve(parent) !== rootAbs && existsSync(parent) && readdirSync(parent).length === 0) {
        rmdirSync(parent)
        parent = dirname(parent)
      }
    } else {
      warnings.push(`stale generated file ${path} was hand-modified; delete it or move changes into everyharness.yaml`)
    }
  }
}
```

The full session-start template (transcribe into `sessionStartScript` as a template literal, with `${'$'}{...}` escaping where needed — the implementer must be careful that TS template-literal `${}` does not swallow bash `${}`; use string concatenation or escaped `\${`):

```bash
#!/usr/bin/env bash
# GENERATED by everyharness — edit everyharness.yaml instead
# SessionStart bootstrap hook for the __PLUGIN_NAME__ plugin (emitted by everyharness)

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
PLUGIN_ROOT="$(cd "${SCRIPT_DIR}/../.." && pwd)"

bootstrap_content=$(cat "${PLUGIN_ROOT}/__BOOTSTRAP_SKILL_DIR__/SKILL.md" 2>&1 || echo "Error reading bootstrap skill")

escape_for_json() {
    local s="$1"
    s="${s//\\/\\\\}"
    s="${s//\"/\\\"}"
    s="${s//$'\n'/\\n}"
    s="${s//$'\r'/\\r}"
    s="${s//$'\t'/\\t}"
    printf '%s' "$s"
}

bootstrap_escaped=$(escape_for_json "$bootstrap_content")
session_context="<plugin-bootstrap plugin=\\\"__PLUGIN_NAME__\\\">\nThe following skill from the __PLUGIN_NAME__ plugin is loaded at session start:\n\n${bootstrap_escaped}\n</plugin-bootstrap>"

if [ -n "${CURSOR_PLUGIN_ROOT:-}" ]; then
  printf '{\n  "additional_context": "%s"\n}\n' "$session_context" | cat
elif [ -n "${CLAUDE_PLUGIN_ROOT:-}" ] && [ -z "${COPILOT_CLI:-}" ]; then
  printf '{\n  "hookSpecificOutput": {\n    "hookEventName": "SessionStart",\n    "additionalContext": "%s"\n  }\n}\n' "$session_context" | cat
else
  printf '{\n  "additionalContext": "%s"\n}\n' "$session_context" | cat
fi

exit 0
```

`__PLUGIN_NAME__` / `__BOOTSTRAP_SKILL_DIR__` are the substitution points (simple `.replaceAll` on the literal — avoids TS/bash `${}` interference entirely). `runHookCmd()` returns superpowers' polyglot verbatim (fetch it from the ground-truth block in the research section of this plan's PR or from `superpowers@dev:hooks/run-hook.cmd`; it is reproduced in the task brief for Task 4 executors below):

```
REM Cross-platform polyglot wrapper for hook scripts.

REM Usage: run-hook.cmd <script-name> [args...]

where bash >nul 2>nul
if %ERRORLEVEL% equ 0 (
    bash "%HOOK_DIR%%~1" %2 %3 %4 %5 %6 %7 %8 %9
```
